# AC Test Client 1.1.0 (Fabric, Minecraft 1.21.4)

Тестовый клиент для проверки собственного античита. Модули включаются **только** в одиночной игре
(`allowSingleplayer`) и на серверах из списка `allowedServers` в `config/actest.json` — на любом другом
сервере клавиши не срабатывают, а уже включённые модули выключаются.

Новое в 1.1.0:

- модули **KillAura** и **AutoTotem** (категория «Бой» в меню, клавиши V и Y);
- их секции `killAura` / `autoTotem` в `config/actest.json` — в конфиг от 1.0.0 они дописываются
  автоматически со значениями по умолчанию, остальные настройки не трогаются;
- строки `[KillAura]` и `[AutoTotem]` в `logs/latest.log` при включённом «Логе движения» (`debugLog`).

## Установка

1. Fabric Loader 0.16+ для 1.21.4 и Fabric API.
2. Положить `release/actest-client-1.1.0.jar` в `.minecraft/mods/` (старый `actest-client-1.0.0.jar` удалить).
3. Запустить игру, добавить адрес тестового сервера в `allowedServers` (как в списке серверов, с портом
   или без) — конфиг перечитывается сам раз в секунду, перезапуск не нужен.

| Модуль    | Клавиша     | Модуль    | Клавиша     |
|-----------|-------------|-----------|-------------|
| Speed     | R           | Reach     | K           |
| Fly       | G           | KillAura  | V           |
| NoFall    | N           | AutoTotem | Y           |
| NoSlow    | — (в меню)  | WH (ESP)  | H           |
| Step      | J           | Меню      | Right Shift |

Переназначить: Настройки → Управление → AC Test Client.

## Архитектура

```
ActestClient            точка входа: конфиг, модули, события Fabric API (тик, рендер мира, HUD)
module/Module           общий интерфейс: getName, toggle, onTick, onRender, getHudInfo
module/AbstractModule   имя + клавиша + флаг включения (onEnable/onDisable)
module/ModuleManager    регистрация модулей, клавиши, тик/рендер, отключение вне allowedServers
module/ServerGuard      проверка singleplayer / allowedServers
module/*Module          Speed, Fly, NoFall, NoSlow, Step, Reach, KillAura, AutoTotem, Wallhack
mixin/*                 NoFall (onGround в sendMovementPackets), WH (контур glowing и его цвет)
config/ActestConfig     config/actest.json (Gson), автоперечитывание при изменении файла
gui/ActestScreen        меню настроек; render/ModuleListHud — HUD-список включённых модулей
```

Новый модуль = класс `extends AbstractModule` + строка `register(new ...)` в `ModuleManager`
(+ при желании секция в `ActestConfig` и страница в `ActestScreen`).

## Новые секции конфига

```json
"killAura": {
  "range": 3.0,            // 1–6, от глаз до ближайшей точки хитбокса (ваниль 3.0)
  "rotation": "PACKET",    // NONE | PACKET | CLIENT
  "priority": "DISTANCE",  // DISTANCE | HEALTH | ANGLE
  "waitCooldown": true,    // бить по ванильному кулдауну атаки; false — с частотой cps
  "cps": 8.0,              // 1–20
  "players": true, "hostileMobs": false, "passiveMobs": false,
  "throughWalls": false,   // бить без прямой видимости
  "swing": true            // HandSwingC2SPacket после удара
},
"autoTotem": {
  "mode": "ALWAYS",        // ALWAYS | HEALTH
  "health": 10.0,          // порог для HEALTH: здоровье + поглощение, в HP
  "method": "SWAP",        // SWAP (1 клик, как F) | PICKUP (2–3 клика)
  "delay": 0               // 0–20 тиков после того, как тотем пропал из второй руки
}
```

KillAura не бьёт игроков в креативе/спектаторе, стойки для брони и прочие не-мобы, а также пока открыт
любой экран (чат, инвентарь, меню). AutoTotem не работает в креативе, при открытом сундуке/другом
контейнере и когда в курсоре мыши есть предмет.

## Что получает сервер (для сверки с логами античита)

### KillAura

Сам удар неотличим от клика мышью: `PlayerInteractEntityC2SPacket` (ATTACK, id цели, sneaking), затем —
если `swing: true` — `HandSwingC2SPacket(MAIN_HAND)`. Удар уходит в конце клиентского тика, **после**
обычного пакета движения этого тика. Детектить нужно контекст:

| Признак | Что видно на сервере |
|---|---|
| `rotation: NONE` | последний полученный поворот игрока не направлен на цель: луч взгляда не пересекает хитбокс (проверки угла/рейкаста) |
| `rotation: PACKET` | в одном тике после обычного пакета движения приходит ещё `PlayerMoveC2SPacket.LookAndOnGround` с углами точно на цель, сразу за ним атака; на следующем тике без удара — `LookAndOnGround` обратно на настоящий взгляд (рывок «туда-обратно», лишний пакет движения в тике) |
| `rotation: CLIENT` | повороты приходят в обычных пакетах движения, удар — тиком позже, но наводка идеальная: каждый тик ровно в ближайшую точку хитбокса, углы не кратны шагу чувствительности мыши (GCD-проверки) |
| `waitCooldown: true` | удары строго в момент полного заряда атаки — одинаковый интервал в тиках, без разброса |
| `waitCooldown: false` | ровно `cps` ударов в секунду с нулевой дисперсией интервалов; удары без заряда (cooldown < 1 в логе) |
| `range` > 3 | дистанция до хитбокса больше ванильной; ванильный сервер проверяет её с запасом, поэтому небольшое превышение должен ловить сам античит |
| `throughWalls: true` | удар без прямой видимости между глазами игрока и целью |
| `swing: false` | атака без `HandSwingC2SPacket` |
| несколько целей | переключение цели по приоритету без «пути» прицела между ними |

С `debugLog` каждая атака пишется так (`age` — тики жизни игрока, как в строках `[Move]`; `yaw`/`pitch` —
углы, которые сервер считает текущими в момент удара; `walls=true` — цели не было видно):

```
[KillAura] age=1834 target=Steve dist=2.874 yaw=-143.27 pitch=11.05 rot=PACKET cooldown=1.00 walls=false
```

### AutoTotem

Клики уходят пакетом `ClickSlotC2SPacket` с `syncId = 0` (инвентарь игрока), экран при этом не
открывается:

| `method` | Пакеты |
|---|---|
| `SWAP` | один пакет: `slot` = слот тотема (9–35 — рюкзак, 36–44 — хотбар), `button = 40`, `SWAP` |
| `PICKUP` | 2–3 пакета в одном тике: (`slot`, 0, `PICKUP`) → (`45` — вторая рука, 0, `PICKUP`) → (`slot`, 0, `PICKUP`), если во второй руке что-то было |

Что можно ловить: клик через ≤ 1 тик после срабатывания тотема (статус 35 в `EntityStatusS2CPacket`) при
`delay: 0`; клики по инвентарю во время движения/спринта/атаки; клики без последующего
`CloseHandledScreenC2SPacket` (ванилла шлёт его при закрытии инвентаря); несколько кликов в одном тике
(`PICKUP`).

```
[AutoTotem] age=2210 slot=38 method=SWAP waited=0 hp=1.0
```

`waited` — сколько тиков модуль ждал перед кликом (настройка `delay`).

### Остальные модули (кратко)

- **Speed**: увеличенное горизонтальное смещение в пакетах движения (`dXZ` в `[Move]`); BHOP —
  прыжок при каждом касании земли с разгоном.
- **Fly**: зависание и движение в воздухе без падения (MOTION) или падение медленнее ванильного (GLIDE).
- **NoFall**: `onGround=true` в пакетах движения во время падения (SPOOF) или дополнительный
  `OnGroundOnly(true)` каждый тик падения (PACKET).
- **NoSlow**: скорость ходьбы без замедления при еде/блоке щитом/натягивании лука и на песке душ/мёде.
- **Step**: подъём на 1+ блок за один тик без прыжка.
- **Reach**: атака и взаимодействие с блоками дальше ванильных 3.0 / 4.5.
- **WH**: только клиентский рендер, на сервер ничего не уходит.

## Сборка из исходников

Нужен JDK 21. В папке проекта:

```
./gradlew build          # Windows: gradlew.bat build
```

Готовый мод — `build/libs/actest-client-1.1.0.jar`. Если Gradle не найдёт версию Yarn или Fabric API
из `gradle.properties`, возьмите актуальные для 1.21.4 на https://fabricmc.net/develop.

## Как собран `release/actest-client-1.1.0.jar`

Исходников 1.0.0 не было — только jar, поэтому `src/` восстановлен декомпиляцией 1.0.0 (Vineflower)
с переводом имён в Yarn 1.21.4; комментарии в старых классах добавлены заново. В среде, где делалась
1.1.0, не было доступа к Maven Fabric и серверам Mojang, поэтому Loom запустить не удалось, и jar
собран так:

- все классы 1.0.0, включая миксины и refmap, оставлены байт-в-байт;
- заново скомпилированы только `ModuleManager`, `ActestConfig`, `ActestScreen` и новые
  `KillAuraModule` / `AutoTotemModule` — javac против заглушек Minecraft API, сгенерированных из маппингов
  Yarn 1.21.4 (имена intermediary, как в рантайме);
- каждая ссылка на Minecraft в новом байткоде сверена с маппингами (имя + дескриптор), а ссылки в
  перекомпилированных старых классах — с байткодом 1.0.0.

В игре этот jar не запускался. Если что-то упадёт, пришлите `logs/latest.log` (и `crash-reports/`, если
есть). Сборка через `./gradlew build` из `src/` даёт эквивалентный мод.
