Нейтральные мобы атакуют только в ответ на удар. У каждого моба есть яйцо призыва и своя таблица лута.

## Медведь
- Скорость `0.195` (бег игрока = `0.1 × 1.3 = 0.13`, ×1.5).
- 28 HP, урон 7 (3.5 сердца).
- Дроп: **4 медвежьих стейка** (еда, 9 голода) и **медвежья шкура** (1–3).
- Из шкуры крафтится броня (как у ванильных наборов): шлем, нагрудник, поножи, ботинки
  (защита 2/6/5/2, прочность ×20, сопротивление отдаче 0.1).

## Сборка
```
./gradlew build        # jar в build/libs/
./gradlew runClient    # запуск игры для теста
```
Нужны JDK 21 и доступ к maven.fabricmc.net.

Текстуры мобов — заглушки (цветной «мех» на ванильных развёртках); модели берутся из ванильных мобов
(медведь — модель белого медведя, лев/ягуар — оцелот, лось/бизон — корова и т.д.) с изменённым размером.
Подробности и настройки статов: `ModEntities.java`, `BearEntity.java`.
